# fav films

Сервис Filmorate умеет работать с фильмами и оценками пользователей, а также возвращать топ фильмов, рекомендованных к просмотру. Есть возможность поиска (по названию и/или режиссёру), добавлены фильтры. А для улучшения рекомендаций по просмотру пользователи объединены в комьюнити. Подключена встроенная база данных.

Стек: Spring Boot, JDBC, H2, Maven; тестирование JUnit + JdbcTest.
